Dynamic by default.Native when known.

Idol is an experimental Lua-derived native compiler. Ordinary source can keep dynamic Lua behavior, then specialize as the compiler proves exact subjects, shapes, worlds, demand, and target facts.

Install Idol Read the language law

The compiler is under active construction. Self-hosting and faster-than-C evidence are goals, not current claims.

One language. Increasing compiler knowledge.

Idol does not replace Lua’s programming model with a second static-language universe. It strengthens the same values and relations as more facts become exact.

01

Lua remains the foundation

Tables, closures, multiple results, metatables, coroutines, and ordinary dynamic behavior remain part of the semantic floor.

02

Meaning lives in one graph

Exact identities, applications, projections, descriptors, worlds, demand, provenance, and witnesses are compiler-published facts—not browser inventions.

03

Representation stays open

Boxing, storage, layouts, calling conventions, vectorization, and target realization remain choices until demanded observations make them necessary.
