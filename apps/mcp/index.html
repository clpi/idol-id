hosted tool transport

Idol MCP

A stateless Streamable HTTP projection of authority-bound Idol tools. The transport validates framing, authentication, scopes, and response bounds. It does not parse source, invent graph meaning, mint worlds, or become a second semantic authority.

transport only semantic authority false session state none least-privilege scopes
canonical endpoint
https://mcp.idol.id/mcp

Authenticate with a digest-only Platform API token carrying mcp:connect plus every scope required by the selected tool. Canonical tool coordinates use the idol.* namespace.

Create API token

Connect without hidden state.

The examples leave the bearer value in an environment variable. This page keeps a pasted token only in the password field and never writes it to localStorage, sessionStorage, cookies, IndexedDB, or the URL.

Discover the server
curl https://mcp.idol.id/mcp \
  -H "Authorization: Bearer $IDOL_TOKEN" \
  -H "Content-Type: application/json" \
  -H "MCP-Protocol-Version: 2026-07-28" \
  -H "Mcp-Method: server/discover" \
  --data '{"jsonrpc":"2.0","id":"discover","method":"server/discover","params":{}}'
List canonical tools
curl https://mcp.idol.id/mcp \
  -H "Authorization: Bearer $IDOL_TOKEN" \
  -H "Content-Type: application/json" \
  -H "MCP-Protocol-Version: 2026-07-28" \
  -H "Mcp-Method: tools/list" \
  --data '{"jsonrpc":"2.0","id":"tools","method":"tools/list","params":{}}'

Discovery

Current clients call server/discover. Compatibility framing never creates server-side session state.

Least privilege

mcp:connect admits the transport. Each tool then requires its own existing scope, such as analysis:read, world:read, or live:write.

Semantic ownership

Tool names are transport coordinates. Compiler identities, graph roles, projections, worlds, witnesses, and derivations come only from their owning producers.
