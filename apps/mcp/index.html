Discovery

Modern clients call server/discover. Legacy initialization remains compatibility transport and does not create server-side session state.

Least privilege

mcp:connect admits the transport. Each tool then requires its own existing API scope, such as live:read, universe:read, or analysis:read.

Semantic law

Tool names are transport coordinates. Compiler identities, graph edges, projections, worlds, witnesses, and derivations come only from their owning producers.
