# Compiler-First Public Reset Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans task-by-task.

**Goal:** Replace the stale ontology-first public system with a readable compiler product, verified examples, safe asset caching, and responsive production admission.

**Architecture:** Keep the existing static/Worker platform but replace homepage and shared chrome, bind public examples to exact compiler evidence, and strengthen build/deployment gates. `clpi/idol` remains sole semantic authority.

**Tech Stack:** Static HTML/CSS/JavaScript, Cloudflare Worker and Assets, Node 22 tests, Chrome DevTools Protocol browser QA.

**Spec:** `docs/superpowers/specs/2026-08-28-compiler-first-public-reset-design.md`

## Global Constraints

- No browser-owned semantic identity or edge inference.
- No law-only source as a homepage default.
- No stable-path immutable caching.
- No superseded public identity.
- Every mobile control is at least 44px and every tested viewport has zero horizontal overflow.

### Task 1: Restore a green production baseline

Remove the merged RED-only Live/MCP contracts whose implementation never landed, preserve their Git history and separate product thesis, and run the complete repository check.

### Task 2: Replace the public product hierarchy

Replace the homepage and shared shell, move secondary tools out of primary navigation, and add permanent superseded-identity tests.

### Task 3: Publish only compiler evidence

Replace the speculative example manifest with compiler-accepted/executed sources, connect Run/Analyze/Native controls to existing APIs, and render only compiler-published graph records.

### Task 4: Repair delivery identity

Revalidate stable assets, reserve immutable caching for content-addressed paths, and remove post-load product rewrites.

### Task 5: Admit the real browser product

Test 320x568, 390x844, 430x932, 768x1024, and 1440x900; exercise mobile navigation, Run, Analyze, exact edge selection, install commands, overflow, touch sizes, and console/runtime errors; merge and deploy only when every gate passes.
